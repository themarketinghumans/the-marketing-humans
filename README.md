# The Marketing Humans

A dependency-free, Apple-inspired marketing agency landing page.

## Files
- index.html
- styles.css
- script.js

## Local preview
Double-click `index.html` or open it in Chrome.

## Free deployment
This static site can be deployed to GitHub Pages or Cloudflare Pages with a custom domain.

## Notes
The visual language is inspired by premium product storytelling: large typography, restrained UI, scroll reveals, depth, glass-like material and smooth transitions. It does not use Apple's trademarks, assets or copied source code.
